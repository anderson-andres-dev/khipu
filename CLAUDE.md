## graphify

Knowledge graph of this codebase at `graphify-out/`.

- Codebase question -> `graphify query "<question>"` first.
- Relationship between two things -> `graphify path "<A>" "<B>"`.
- One concept -> `graphify explain "<concept>"`.
- Broad architecture review only -> `graphify-out/GRAPH_REPORT.md`.
- After modifying code -> `graphify update .`.
